# RideWave
Plateforme de location de voitures premium
📌 Vue d’ensemble

Cette application est une plateforme de location de voitures premium permettant aux utilisateurs de rechercher, réserver et gérer des véhicules en temps réel.
Elle inclut également un espace administrateur pour la gestion complète de la flotte et des réservations.

⚙️ Stack technique
Frontend
HTML5
CSS3
JavaScript (Vanilla)
Interface dynamique avec animations (Hero animé, flip cards 3D)
Backend
Node.js
Express.js
JWT (authentification sécurisée)
Middleware (gestion des routes et sécurité)
Base de données
MySQL
3 tables principales :
users
voitures
reservations

🚀 Objectif du projet

Créer une plateforme complète de location de voitures avec une expérience utilisateur fluide, un backend sécurisé et un système de gestion efficace côté administrateur.
